# hmf_djerba

[Djerba](https://github.com/oicr-gsi/djerba) plugins for use with the Hartwig Medical Foundation (HMF) pipeline.

To make the plugins in this repository available to Djerba:
- Set the environment variable `DJERBA_PACKAGES` to include `hmf_djerba`, for example: `export DJERBA_PACKAGES=hmf_djerba:djerba`
- Ensure Python packages in this repository are installed and visible on the `PYTHONPATH` environment variable.
